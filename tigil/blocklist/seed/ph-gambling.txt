# Tigil — curated Philippines gambling seed list

# PURPOSE
#   Upstream global feeds (StevenBlack, BlocklistProject) cover ~349k casino
#   domains but under-cover the Philippine market. This file adds the operators
#   that are actually promoted here — by influencers, by e-wallet banners,
#   and on TV/PBA/PVL sponsorships.
#
# SCOPE NOTE (read this before editing)
#   This list deliberately includes BOTH:
#     (a) PAGCOR-licensed / PIGO operators — legal, but the user of this app has
#         chosen to block them. Legality is not the criterion; the user's own
#         commitment is.
#     (b) unlicensed / offshore operators and e-sabong, which are illegal in PH.
#   An operator appearing here is NOT an accusation of wrongdoing. Domains in
#   the "licensed" section are lawful businesses. This is a self-control tool,
#   the way an alcohol-blocking app lists licensed liquor retailers.
#
# VERIFICATION STATUS
#   Entries marked [v] were seen in search results / public reporting during
#   research. Entries marked [?] are pattern-derived (common mirror shapes) and
#   should be verified against the authoritative sources in ../SOURCES.md
#   before a production release. The keyword engine (seed/keywords.txt) is what
#   actually carries the load against mirror churn — this file is the anchor.
